NEON TIC TAC TOE - SHARE ONLINE

This folder is ready to publish as a static website.

Easiest method:
1. Open https://app.netlify.com/drop in your browser.
2. Sign in / create an account if asked.
3. Extract this ZIP first, then drag the extracted folder (the folder containing index.html) onto the page.
4. Netlify will publish the game and provide a public URL.
5. Share that URL with friends. They can play in their browser.

Do not upload only the index.html file if the site asks for a folder; upload the extracted folder.
